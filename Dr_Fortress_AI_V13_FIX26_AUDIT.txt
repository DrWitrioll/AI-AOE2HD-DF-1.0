BUGS FOUND AND REPAIRED
-----------------------
1. EXACT-TIER PHANTOM SUCCESS BUG
   FIX25 generated family dispatcher contained 348 higher/exact-tier train branches
   that could execute train <tier>, clear the family request and advance the cycle
   without first proving can-train <tier>. With custom DAT costs/queues this allows
   a failed train command to be recorded by the algorithm as success.
   FIX26 transactional family train actions checked: 744
   Family train actions still lacking exact can-train: 0
   Training actions lacking either can-train or can-train-with-escrow anywhere in
   the whole active script: 0 []

2. CASTLE+ LEGACY FLOOR DOMINATED HIGH TIERS
   FIX25 emergency floor used Spearman/Skirmisher/Archer/Militiaman even in
   Castle/Imperial whenever military population <16. That is exactly the state
   reached after losses, so the recovery path continuously reinforced low tiers.
   FIX26 keeps the cheap floor Feudal-only. Castle+ floor rotates strongest
   researched TRAINABLE model across spear/archer/skirmisher/infantry/knight/
   mangonel families. Models represented:
   arbalest, archer, cavalier, champion, crossbowman, elite-skirmisher, halberdier, imperial-skirmisher, knight, long-swordsman, man-at-arms, mangonel, militiaman, onager, paladin, pikeman, siege-onager, skirmisher, spearman, two-handed-swordsman

3. ONE-SECOND EMPTY ROTOR HOT LOOP
   FIX25 advanced an unavailable emergency-production slot after only one second.
   With missing buildings/resources this could spin indefinitely at 1 Hz while
   producing nothing. FIX26 production-floor 1-second retries remaining: 0.
   Empty slots now use a bounded four-second retry cadence.

4. RELATIVE-PRESSURE IMMEDIATE RE-ENTRY LOOP
   During FIX26 audit, an initial 45-second relative-pressure design was found to
   be able to expire and immediately re-enter on the same still-favorable state.
   Final FIX26 adds df26-relative-cooldown + a separate cooldown timer. Relative
   entry rules: 4; entries missing cooldown guard: 0.
   Rescue/Defense/Recovery interrupt relative pressure and start a cooldown.

5. FALSE CIVILIAN DIAGNOSTIC
   The replay line "Civilian production and task allocation fell below acceptable
   levels" was a random late-game failure explanation; FIX25 did NOT measure own
   civilian population in that rule. FIX26 gates that message on civilian-pop <65
   so it no longer claims a specific diagnosis without a matching signal.

6. CIVILIAN STABILITY / TRAVEL SAFETY
   Hardest receives NO resources. A minimum villager-production floor now applies
   at Feudal <30 and Castle+ profile floors 60 / 75 / 90 for pop 125 / 150 / 200+.
   can-train villager remains mandatory, so age-up/queue/pop/resource legality is
   respected. Final camp/drop travel bounds override legacy late-game values that
   could reach 80-120 tiles; Defense/Recovery contracts them further.

7. RELATIVE ATTACK STRENGTH
   No unsupported arithmetic comparator was introduced. Favorability is expressed
   as conservative parser-proven bands using every-enemy, preventing one weak enemy
   in a team game from authorizing an attack while another enemy has a large army.
   Pressure windows reuse Single Attack Owner and remain subordinate to Ally Rescue.
